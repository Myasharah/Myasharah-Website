# Myasharah — Professional Portfolio

A responsive personal portfolio for Myasharah, designed with a refined neon-blue futuristic visual system.

## Portfolio highlights

- Professional profile and education at Universiti Kebangsaan Malaysia
- Professional skills, leadership and selected organisational roles
- Detailed final-year research methodology, findings and contribution
- Achievements, facilitation, community work and university journey
- Responsive navigation and accessible keyboard, motion and focus behaviour

## Website files

The deployable static website is in [`dist`](./dist):

- `index.html` — site structure and content
- `styles.css` — responsive visual system
- `script.js` — navigation, reveal effects, progress and email-copy interaction
- `assets/hero-art.png` — portfolio hero artwork

Open `dist/index.html` directly, or serve the `dist` folder with any static web server.
